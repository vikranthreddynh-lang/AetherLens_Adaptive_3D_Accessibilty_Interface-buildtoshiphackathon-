# Privacy, Data Isolation & Retention Policy

SenseWeave adheres to strict data minimization, user dignity, and privacy principles:

## 1. Zero Raw Media Storage
- Raw environmental audio recordings and video frames are never stored, written to disk, or retained.
- Sampled frames and audio chunks exist exclusively in volatile memory buffers during real-time inference cycles and are immediately discarded.

## 2. No Biometric Identification
- SenseWeave strictly prohibits biometric profiling.
- No facial recognition, facial landmark embeddings, or voiceprints are created.
- Conversational participants are assigned anonymous temporary session labels (`Speaker A`, `Speaker B`) that expire upon session termination.

## 3. Explicit User Consent
- Device sensors (camera, microphone) are never initialized automatically.
- Media capture begins only after explicit user interaction and positive confirmation of the Privacy & Processing Consent agreement.
- Users can independently disable camera or microphone at any instant during live monitoring.

## 4. Row Level Security (RLS) Isolation
- All user-owned database tables (`profiles`, `saved_sessions`, `saved_events`) enforce PostgreSQL Row Level Security (RLS).
- Sessions and events are bound to `auth.uid() = user_id`.
- Users cannot query, view, modify, or delete another user's saved session data.

## 5. Ephemeral Ticket Security
- Real-time WebSockets authenticate using cryptographically secure single-use tokens generated by `TicketStore`.
- The backend stores only SHA-256 hashes of tickets.
- Tickets expire in 60 seconds and are invalidated on first connection.

## 6. Account Deletion Workflow
- Users can delete individual saved sessions or execute permanent account deletion under Settings > Privacy.
- Deleting an account executes cascading removal of profile records, session recaps, and event records from the database.
